Deployed 3 production AI agents (course-content reviewer, job-description generator, tender finder)
for 5–10 academic staff, reducing task turnaround from 2–3 days to under 3 hours and saving an

LLM evaluation framework (LLM-as-a-Judge / CARE benchmark) using Python and Playwright to execute
automated regression test suites, score agent outputs against ground-truth criteria, and eliminate
prompt regressions prior to deployment.
